# Ridhi Garg — Portfolio

A responsive personal portfolio built with React, TypeScript, Vite, and CSS.

## 1. Install the tools

Install:
- Node.js (LTS): https://nodejs.org/
- Visual Studio Code: https://code.visualstudio.com/
- Git: https://git-scm.com/

## 2. Open the project

Unzip the folder, then open `ridhi-portfolio` in VS Code.

In VS Code, open **Terminal → New Terminal** and run:

```bash
npm install
npm run dev
```

Vite will print a local address, usually `http://localhost:5173`. Ctrl-click it to preview the site.

## 3. Personalize before publishing

Search the project for these placeholders and replace them:
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`
- `Previous Internship` and its description/dates
- Any project details that don't accurately describe your work

The SelectFi and course-project descriptions are starter copy. Verify every detail before publishing.

## 4. Add your resume

Put a PDF copy of your resume in the `public` folder and name it:

`Ridhi-Garg-Resume.pdf`

The Resume link in the navigation will then work.

## 5. Build a production version

Run:

```bash
npm run build
```

Vite creates the optimized site in the `dist` folder.

## 6. Publish with Vercel

1. Create a GitHub repository and push this project.
2. Sign in at https://vercel.com/ with GitHub.
3. Choose **Add New → Project** and import the repository.
4. Keep the detected Vite settings and deploy.
5. Vercel gives you a public URL you can add to your resume.

## Before sharing internship work

Only publish details, screenshots, demos, or code that your manager/company has explicitly approved. Do not expose private source code, customer information, internal URLs, credentials, or confidential business details.
